# Mohamed Ali - a DEPI Project

A simple static website built to showcase Mohamed Ali's lifespan. This site is designed using HTML and CSS, with a focus on clean layout and responsive design.

## 🌐 Live Preview

You can open `index.html` directly in your browser to view the homepage. The `castle.html` page offers additional content or a themed section.

## 📁 Project Structure

- `index.html` – Main landing page
- `castle.html` – Secondary page with themed content
- `style.css` – Custom styles for layout and design
- `images/` – Folder containing visual assets

## 🛠️ Technologies Used

- HTML5
- CSS3
- Basic file structure for static hosting
